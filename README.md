A 2D space shooter multimedia application developed using **HTML5 Canvas**, **CSS**, and **JavaScript**.  
The game demonstrates the stages of the **computer graphics pipeline** including:

- Application Stage
- Geometry Stage
- Rasterization Stage

This project was developed as part of a **Multimedia Applications** coursework assignment.

---

# Project Overview

The Space Shooter Game is an interactive arcade-style game where the player controls a spaceship and shoots incoming enemies or asteroids while trying to survive as long as possible.

The application uses the HTML5 Canvas Graphics API for rendering all game objects and animations in real time.

---

# Features

- Player-controlled spaceship
- Enemy ships / asteroids
- Bullet shooting mechanics
- Collision detection
- Real-time animation loop
- Score tracking system
- Keyboard controls
- Game over condition
- Dynamic object movement

---

# Technologies Used

- HTML5
- CSS
- JavaScript
- HTML5 Canvas API
